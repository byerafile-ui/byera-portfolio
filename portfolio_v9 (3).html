🚀 Deploy to Netlify
1
Save your HTML file
Download this file — it's your complete portfolio, all in one .html file. No separate CSS or JS needed.
💡 Everything is saved in your browser's localStorage. Use Admin → Export JSON to back up your data before deploying.
2
Go to netlify.com
Create a free account at netlify.com — use your email or GitHub. It's completely free for personal portfolios.
3
Drag & Drop Deploy
On your Netlify dashboard, find the Sites section. Drag your portfolio.html file directly into the deploy box. Netlify will instantly publish it!
⚡ Rename the file to index.html before dropping for cleanest URL format.
4
Get your live URL
Netlify gives you a free URL like yourname.netlify.app. You can rename it in Site Settings → Domain Management.
5
Update after changes
When you edit your portfolio (add projects, update info), just download the updated file and drag it to Netlify again — it updates instantly. Your admin data persists in localStorage per device, so export a JSON backup regularly from Admin → Settings.
🔑 For data to show across devices: use Admin → Export, then Import on each device. Or paste your data into the default values in the code.
6
Custom Domain (optional)
Go to Domain Settings → Add custom domain. Point your domain's DNS to Netlify. They provide free SSL certificates automatically.
Admin Access
Enter your password to access the portfolio dashboard.
